# Staff Birthday Bot

A Telegram bot that keeps a company's staff birthdays and Kazakhstan public holidays, sends a morning digest at 09:00
(Almaty time), renders a personalised greeting card for every birthday person and drafts the greeting text with
Google Gemini. A Google Sheet is the single source of truth; a Telegram Mini App shows the team calendar.

![Demo cards and holiday poster](docs/screenshot.png)

> All data in this repository is randomly generated; brand names are anonymized.

## Features

- **Morning digest** — owner gets today's birthday cards with ready-to-forward greeting text, reminders 7/2/1 days
  ahead, upcoming public holidays, a weekly list of colleagues without a known birthday, and a gift-collection prompt.
  Approved staff get a lighter digest (dates only, no texts) and can mute it.
- **Greeting cards** (`card.py`) — Pillow draws the name on a male/female background, auto-fitting font size to two
  lines (surname + given name).
- **AI greetings** (`ai.py`) — Gemini writes a short Kazakh greeting in the style of earlier texts (few-shot), with
  model fallback on 429/503 and JSON-mode parsing; gender is guessed from the patronymic if the sheet doesn't say.
- **Kazakhstan holidays** (`kz_holidays.py`) — fixed and floating dates (Kurban Ait), five-day-week day-off transfer
  rules, posters generated by `design/make_holiday_posters.py`.
- **Google Sheet sync** — the bot reads the sheet as CSV (cached, at most every 2 minutes); an Apps Script web app
  (`apps_script.template.gs`) lets the bot add/delete people, write dates and texts, archives people missing from the
  HR list and acts as a second "alarm clock".
- **Access control** — `/start` creates an access request; the owner approves/rejects with inline buttons.
- **Telegram Mini App** (`web/calendar.html`) — month grid, upcoming birthdays, "wish wall"; Telegram `initData`
  HMAC is verified on the server. Opens in an offline demo mode in a normal browser.
- **Gift collection** — the owner starts a collection, colleagues tap "I've paid", a live board tracks progress.
- **Hosting** — long-polling on a PC (Windows Task Scheduler watchdog: `autostart.ps1`, `start.bat`, `stop.bat`) or
  webhook mode on PythonAnywhere (`webhook_app.py`, Flask) woken hourly by GitHub Actions; idempotent morning sends
  (re-requests only deliver to recipients that were missed).
- **Excel import** (`import_excel.py`) — header detection in Kazakh/Russian/English, Excel serial dates, `dd.mm[.yyyy]`.

Bot UI is in Russian (owner) and Kazakh (staff).

## Tech stack

Python 3.12 · python-telegram-bot 21+ (JobQueue, ConversationHandler, PicklePersistence) · Pillow · NumPy ·
Flask · openpyxl · Google Gemini REST API · Google Sheets + Apps Script · GitHub Actions · HTML/CSS/JS (Telegram Web App)

## Project structure

```
bot.py                     Telegram bot: commands, menus, access control, morning digest, wishes, gifts

card.py                    greeting card renderer
ai.py                      Gemini greeting generator
kz_holidays.py             Kazakhstan public holidays + day-off transfer rules
notify_once.py             one-shot morning send (server cron / /morning endpoint)
webhook_app.py             Flask app for webhook hosting (+ /morning, /selftest, Mini App API)
demo.py                    offline demo (no token needed)
import_excel.py            import staff from an .xlsx
apps_script.template.gs    Google Sheet automation (secrets are placeholders)

web/calendar.html          Telegram Mini App
design/                    background/poster generators, placeholder logo, AI holiday backgrounds
cards/                     generated card backgrounds, holiday posters, Roboto Bold font
data/birthdays.json        generated fake team (40 people)
scripts/generate_demo_data.py  fake data generator
.github/workflows/         hourly wake-up for the hosted bot
```

## How to run (demo mode)

No Telegram token, Google Sheet or API key is needed.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt

python demo.py                  # today's birthdays, reminders, /soon list, holidays → cards in output/
python demo.py --date 2026-11-25   # a day with birthdays in the demo data
```

Open `web/calendar.html` in a browser to see the Mini App in demo mode.

Regenerate the fake data / artwork:

```bash
python scripts/generate_demo_data.py --seed 7   # new random team + Mini App demo block
python design/make_demo_backgrounds.py          # neutral card backgrounds + placeholder logo
python design/make_holiday_posters.py           # holiday posters from design/holiday_backgrounds/
```

### Running the real bot

1. `cp .env.example .env` and fill in `BOT_TOKEN` (from @BotFather); optionally `SHEET_ID`, `GEMINI_API_KEY`.
2. `python bot.py` (long polling). The first user who sends `/start` becomes the owner (or set `OWNER_ID`).
3. Optional hosting: upload to PythonAnywhere, `python webhook_app.py setup https://<host>/telegram`, set the
   repository secrets `BOT_SERVER_URL` and `WEBHOOK_SECRET` for the GitHub Actions wake-up.
4. Optional sheet automation: paste `apps_script.template.gs` into the sheet's Apps Script editor, replace the
   `__…__` placeholders, run `setup`, deploy as a web app and put its URL into `SHEET_WEBAPP_URL`.

## Қысқаша (KZ)

Компания қызметкерлерінің туған күндерін еске салатын Telegram-бот. Күн сайын таңертең туған күн иесінің
есімі жазылған құттықтау карточкасын салып, Gemini арқылы қазақша құттықтау мәтінін дайындайды.
Қазақстанның мерекелерін, демалыс күндерінің ауысуын ескереді, Google-таблицамен синхрондалады.
Telegram Mini App ішінде команданың туған күндер күнтізбесі бар. Демо: `python demo.py` — токенсіз жұмыс істейді,
барлық деректер кездейсоқ жасалған.
